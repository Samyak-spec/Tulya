# Future Features

Prioritize only after MVP is stable.

## High value
- Price/discount history
- Deal alerts
- Restaurant availability
- Group budget splitting
- Occasion-aware recommendations
- "Surprise me"
- AI conversational food discovery
- Menu-item comparison
- Personalized deal feed

## Advanced
- Learned ranking model
- Vector search for semantic restaurant discovery
- Review summarization
- Food image understanding
- Multi-person preference optimization
- Dynamic budget optimization
- Loyalty/rewards comparison

## Avoid early
- Building payments
- Excessive microservices
- Autonomous ordering
- Unverified scraping
- Complex ML before enough interaction data exists
