# UI/UX Specification

## Design direction
Modern, premium, minimal, food-focused and highly visual.

Use:
- React
- Tailwind CSS
- Framer Motion
- Lucide icons
- Responsive cards
- Smooth transitions
- Clear pricing hierarchy

## Main pages

### Home
- AI search bar
- Dine-out / Delivery selector
- Budget selector
- Cuisine chips
- Popular searches
- Personalized section for signed-in users

### Results
- Search summary
- Filter sidebar/drawer
- Restaurant cards
- Platform offer comparison
- Best deal badge
- Final effective price
- Savings
- Rating
- Distance
- Redirect button

### Restaurant detail
- Hero image
- Restaurant information
- Menu
- Platform comparison
- Offers
- Map/location
- Similar restaurants

### Profile
- Preferences
- Favorites
- Search history
- Preferred platforms

## Restaurant card
Show:
- Image
- Name
- Cuisine
- Rating
- Price range
- Distance
- Best platform
- Original price
- Discount
- Final price
- Savings
- CTA

## Motion
Use Framer Motion for:
- Page transitions
- Card entrance
- Filter changes
- Offer comparison expansion
- Recommendation reveal

Avoid excessive animation.

## Accessibility
- Keyboard navigation
- Proper labels
- Focus states
- Semantic HTML
- Color contrast
- Reduced-motion support
